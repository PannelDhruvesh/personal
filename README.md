# Its Billi ❤️

A private, secure, and beautiful memory storage website built with love.

## Tech Stack

- **Frontend**: HTML5, CSS3, Vanilla JavaScript → Vercel
- **Backend**: Python, FastAPI → Render
- **Database**: Supabase PostgreSQL
- **Storage**: Supabase Storage
- **Auth**: JWT + bcrypt

## Quick Start

See [docs/INSTALL.md](docs/INSTALL.md) for full setup instructions.

## Features

- 🔐 Secure JWT Authentication
- 📸 Photo & Video Storage
- 📁 Album Management
- 🗑️ Trash & Restore
- 🔍 Search
- 📥 Download (individual + ZIP)
- 💾 Storage Usage Tracking
- 🌙 Dark Mode
- 📱 Mobile First Design
